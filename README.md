# SkyVigil

SkyVigil is a live air-quality and climate intelligence dashboard for BRICS+ and global regional corridor monitoring.

## Features
- Real-time AQI monitoring
- Hotspot and plume visualization
- AI vision and anomaly detection workflows
- Federated model mesh and governance panels
- Express + Socket.IO backend API

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express, Socket.IO

## Run locally
```bash
npm install
npm start
```

Then open:
- http://localhost:4000

## Environment
- Keep secrets in `.env` locally.
- `.env` is ignored by Git.
